# 跨群读取由提问者负责

跨群读取最初由三道门守着：提问用户属于来源群、Agent 属于来源群、来源群成员包含目的群全部成员（受众覆盖），投递前还会用第三道再复核一次。第二道的依据是「受限群内容不能流向受众更广的群」。现在只保留前两道的成员身份检查，删掉受众覆盖与投递复核；Agent 私有记忆也从「按来源群分文件、按受众继承」改为每个 Agent 一篇、各群共享。

理由：

- 用户主动提问是明确的行为。该不该把这个群的内容说到另一个群，产品不该替他判断；拦截只会让人拿到一句莫名其妙的拒绝。
- Agent 是群成员而不是工具，它知道的东西不该因为换了个群就凭空消失。
- 真正要防的是静默、无意识的披露；有提问者、有记录的请求，责任在提问者。

后果：

- 来源群成员可以把受限群的内容问进成员更多的群，包括默认群；这部分风险由提问者承担。
- 群里其他无权访问来源群的成员可能因此看到内容，产品不做额外提醒，也不替换回答。
